# 🌍 Language Translation Tool

## About the Project

The Language Translation Tool is a simple web application developed using Python and Streamlit.

It allows users to translate text from one language to another using an external translation API.

## Features

- Simple and user-friendly interface
- Multiple language selection
- Text translation
- Translation result display
- Input validation
- Error handling

## Technologies Used

- Python
- Streamlit
- Requests
- MyMemory Translation API

## Supported Languages

- English
- Tamil
- Hindi
- Telugu
- Malayalam
- Kannada
- French
- Spanish
- German

## Installation

Install the required Python packages:

    python -m pip install -r requirements.txt

## How to Run

Run the following command in the terminal:

    python -m streamlit run app.py

The application will open in your web browser.

## Requirements

- Python installed
- Internet connection

## Note

Translation results depend on the external translation service.
Translation availability and accuracy may vary.
